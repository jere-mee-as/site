# lab/marathon

Reference sheets for the Marathon "graphic realism" direction, which is the style the live site at jere.ing uses now. The type specimen locks the type system; the color map shows which colors each section of the site uses and where. These are original pages inspired by the Marathon UI style; no game assets are included.

| File | What |
|---|---|
| `type-specimen.html` | Type specimen: the site's typefaces, sizes and weights in use |
| `color-map.html` | Color map: the palette and which section uses which colors |

## How to open

Open either file in a browser. Fonts load from Google Fonts.

## Status

Current. These match the live site; update them when the type or color decisions change.

## Docs

No docs folder here. The decisions these pages record are in [`../../docs/site/`](../../docs/site/) (`jrl-site-restyle-plan.md`, `jrl-v3-1-decisions.md`).

The Marathon style book and style videos are private reference material kept outside the repo.
