# lab/mirrors-edge

A Mirror's Edge-inspired direction. Two strands: the runner site (jere.ing redone in this style, with a preview and a template), and vesta 9, an in-world site for a fictional residential building, with a field guide to the city web it belongs to. These are original pages inspired by the Mirror's Edge UI style; no game assets are included.

| File | What |
|---|---|
| `runner.html` | The runner site: jere.ing in this style |
| `preview.html` | Runner preview with a sample report list |
| `template.html` | Runner template, drop-in for the root `template.html` (keeps the `<!-- LIST -->` marker) |
| `runner-stylebook.html` | Stylebook for the runner site |
| `vesta9.html` | vesta 9 Residences, the in-world site (current) |
| `vesta9-v1.html` | vesta 9, first version |
| `city-web-field-guide.html` | Field guide to the city web that vesta 9 sits in |

## How to open

Open any file in a browser. Fonts load from Google Fonts; some pages link out to Are.na and Substack.

To try the template against the real report list, copy it over the root `template.html` locally and run `build.py` (see the root README). Don't commit that swap.
