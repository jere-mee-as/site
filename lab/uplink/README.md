# lab/uplink

Marathon pass 2. Uplink is the site reimagined as an in-world object: the shell a runner would use, rather than a website styled like one. The stylebook is its visual development book: the rules, parts and studies behind the site. These are original pages inspired by the Marathon UI style; no game assets are included.

| File | What |
|---|---|
| `index.html` | The Uplink concept as it was on Nov 8, with hard-coded reports. The live version is the root `template.html`, which reads the report list `build.py` generates, uses the renamed Are.na channels and has an `archive` terminal command |
| `stylebook.html` | Uplink visual development book |

## How to open

Open either file in a browser. Fonts load from Google Fonts; a few links point out to external sites.
